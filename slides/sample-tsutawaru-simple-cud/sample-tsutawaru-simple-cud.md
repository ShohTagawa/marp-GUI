## Only the colours differ from tsutawaru-simple

- **Band colours**
  The accent colours of the CUD colour set, unchanged.
- **Text colours**
  The same hues, darkened to contrast 4.5 or more on white.
- **Cues besides colour**
  Emphasis is also bold; each divider also carries a title.

<div class="takeaway">Bands, spacing and layouts are as in tsutawaru-simple</div>

## The bands use the values of the set as they are

| _class | Colour in the set | Screen RGB |
|---|---|---|
| blue (default) | Blue | 0, 90, 255 |
| red | Red | 255, 75, 0 |
| orange | Orange | 246, 170, 0 |

<div class="attr">Source: CUD recommended colour set guidebook, 2nd ed. (2018), p.2 [in Japanese]. 制作：カラーユニバーサルデザイン推奨配色セット制作委員会 (Color Universal Design Recommended Color Set Committee)</div>

<div class="takeaway">yellow gives orange; garnet gives red</div>

| _class | Colour in the set | Screen RGB |

| sky | Sky blue | 77, 196, 255 |
| gray | (outside the set) | 77, 77, 77 |

<div class="attr">Source: the same guidebook, p.2. The guidebook marks the set's grey with blue as △ (p.8), so a darker grey is used.</div>

<!-- _class: gray -->

## What was checked, and what was not

- **Checked**
  Colour differences and contrast ratios, computed for four types of colour vision.
- **Not checked**
  No check yet by people with colour-vision deficiency.
- **Version of the set**
  Values of ver.4 (2018); ver.4.2 values not checked.

<div class="takeaway">The computation is a guide; asking viewers is the sure check</div>
