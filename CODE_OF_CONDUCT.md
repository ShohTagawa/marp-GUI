# Code of Conduct

[日本語は下にあります](#日本語)

marp-GUI adopts the **Contributor Covenant, version 2.1**, as its code of conduct:
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

It applies in all project spaces (issues, pull requests, discussions and reviews on GitHub) and whenever someone represents the project in public.

## Reporting

Reports go to the maintainer through GitHub:

- If the report should not be public, use the repository's private reporting form (**Security** tab → **Report a vulnerability**) and start the title with "Code of conduct".
- Otherwise, open an issue.

The maintainer keeps the reporter's identity confidential and follows the Covenant's enforcement guidelines (correction, warning, temporary ban, permanent ban).

## 日本語

marp-GUI は行動規範として **Contributor Covenant 2.1**（上の URL）を採用します。GitHub 上の issue・pull request・議論・レビューと、プロジェクトを代表して公の場に出るときに適用します。

報告は GitHub で管理者へ。公開したくない報告は、リポジトリの **Security** タブ →「**Report a vulnerability**」の非公開フォームを使い、題名を「Code of conduct」で始めてください。それ以外は issue で受け付けます。報告者の名前は伏せ、Covenant の執行の指針（注意・警告・一時的な参加停止・恒久的な参加停止）に従って対応します。
